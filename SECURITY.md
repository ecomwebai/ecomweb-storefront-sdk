# Security

Please report a vulnerability in `@ecomweb/sdk` or `@ecomweb/storefront-kit`
privately, through GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/ecomwebai/ecomweb-storefront-sdk/security/advisories/new)
(the Security tab of this repository). Do not open a public issue.

Include the package and version, what an attacker can do, and the steps to
reproduce it. We reply within a few working days and credit you in the
advisory unless you prefer otherwise.

Fixes ship as new package versions; the platform tells store owners running an
affected version to update (`ecomweb storefront upgrade`). Only the latest
minor version gets fixes.
